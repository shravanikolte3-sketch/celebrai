# CelebrAI

CelebrAI is a polished demo-mode event planning workspace built with React, TypeScript, Vite, Recharts, and Lucide icons.

## Run locally

1. Install Node.js 18+.
2. From this folder, run `npm install`.
3. Run `npm run dev`.

The prototype uses the required Pune birthday scenario as local demo data. The copilot, budget editing, timeline checkboxes, vendor search/save controls, charts, and what-if simulator are functional without an API key. Vendor cards are explicitly sample data and all prices are labeled estimates.
